# Analytics and Early Warning

## Scope and operating instructions

- Define metrics before dashboards: competitor activity, price index, changes, source freshness, verification backlog, win/loss, alert precision.
- Normalize prices per comparable unit and currency with dated conversion rates; expose assumptions.
- Distinguish observed changes from inferred trends and forecasts; show confidence intervals where meaningful.
- Implement threshold, anomaly and multi-signal alert rules with cooldown, deduplication and human escalation.
- Build executive, analyst and field dashboards with drilldown to evidence.
- Evaluate alerts for false positives, missed signals, latency and usefulness.
- Reports include source links, observation windows, authorship, verification status and generated-at timestamp.
