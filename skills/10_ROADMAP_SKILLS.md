# Delivery Roadmap and Definition of Done

## Scope and operating instructions

Phase 1: foundation, users/RBAC, competitor and product registries, manual evidence capture, audit and dashboard.
Phase 2: prices, search, reporting, alerts, validation workflows and data quality.
Phase 3: lawful collectors, source snapshots, scheduled ingestion and review queues.
Phase 4: hybrid RAG, evidence-backed AI summaries, verification and battlecards.
Phase 5: push-to-talk voice, PWA, field reporting, then streaming conversation.
Phase 6: forecasting, relationship graphs, advanced alerting and scaling.

Each feature is done only with: requirements, threat model, schema, permission checks, tested implementation, accessible UI, monitoring, documentation, migration and rollback path.
