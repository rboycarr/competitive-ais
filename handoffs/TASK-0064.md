## Objective
P1-32a, the first slice of P1-32 (PO decisions 2026-11-03: two slices; O32). Analysts upload evidence into quarantine. The scan, blobs and promotion to the locked `evidence` bucket follow in P1-32b. Context: `handoffs/SESSION-2026-11-03.md` §4 and §6.

- **Dependency** (on the PO-approved Phase 1 list):
  - `league/flysystem-aws-s3-v3` 3.35.3;
  - `aws/aws-sdk-php` 3.401.4, pinned as a direct requirement because the newest release was 4 days old;
  - `aws/aws-crt-php`, `mtdowling/jmespath.php` and `symfony/filesystem` come with them.

  `composer audit` reports no advisories. Recorded in ADR-0003.
- **`s3-private` driver** (`PlatformServiceProvider::privateObjectStorage`, `Modules\Platform\Storage\PrivateBucketVisibility`):
  - **The problem:** Flysystem adds `ACL: private` to every write, and SeaweedFS refuses that from the application's key, which holds no ACL permission. This was proven against the local store: the same PutObject succeeded without the header and got AccessDenied with it.
  - **The fix:** the driver's visibility converter returns an empty ACL, which the SDK omits. Checked on a single upload and on a 20 MB multipart upload.
  - **Not done instead:** giving the key ACL rights, because an ACL could make an object public.
  - **Same plumbing:** the S3 client and the Laravel `AwsS3V3Adapter` are the same as for `s3`, so pre-signed URLs work for P1-34.
- **Schema** (`modules/Evidence/database/migrations/2026_11_18_000100_create_evidence_assets_table.php`):
  - `evidence_assets`: grant class `no_delete`;
  - `evidence_custody_events`: `append_only`, already listed;
  - CHECKs for values, the file name, the source URL, and the status/scan/quarantine-key states;
  - DATETIME(6) throughout;
  - rollback refused while assets exist.
- **`EvidenceUploadService`:**
  - `evidence.upload` required;
  - size between 1 byte and `evidence.max_bytes` (50 MB);
  - the type is detected from the bytes with `finfo`, never from the browser or the name (Laravel's fake upload reports a type from the name) and must match the extension (`config/evidence.php`);
  - the file name is cleaned for display and never used as the key, which is `quarantine/<ulid>`;
  - the classification can't be above the uploader's clearance;
  - the source URL is http(s) without credentials, recorded and never fetched;
  - `captured_at` is UTC and not in the future.
  - **Write order:** the object is written first; then the asset, the `uploaded` custody event and the audit event (classification only) go in one transaction; if that fails, the object is deleted.
- **Visibility** (`EvidenceAsset::seenBy`, O32): AccessScope on the classification. Until an asset is `available` (or `withdrawn`), only its uploader and `evidence.hold` holders see it; others get 404. No content is served (downloads: P1-34).
- **Pages:**
  - Evidence list with a status filter, and the upload form (form data, capture time converted to UTC);
  - detail page with a quarantine notice, metadata and the custody timeline;
  - a navigation link for `evidence.view` holders.

## Review focus
1. **Untrusted uploads:**
   - type detection and the extension match: spoofing, polyglots, text types such as HTML or SVG;
   - the size limit and where it is enforced (PHP, nginx, form request, service);
   - file-name cleaning and display (XSS);
   - anything that could make the store or the app fetch or execute content.
2. **Storage:**
   - the `s3-private` driver: anything Flysystem or Laravel still sends that needs a permission;
   - error handling: `throw` is true;
   - the write order and the orphan cleanup, and what happens if the delete fails;
   - the quarantine key.
3. **Authorization and visibility:** who sees quarantined or rejected uploads (O32), the 404 behaviour, the classification ceiling, and the AccessScope matrix.
4. **Schema and grants:** the CHECKs, the state rule (does it fit the scan transitions P1-32b needs?), `no_delete` and `append_only`, the rollback.
5. **Dependency:** the pins and the transitive packages.
6. **Tests:** gaps in `EvidenceUploadTest`, `PrivateObjectStorageTest` and `Evidence.test.ts`.

Please mark anything that is not a merge blocker as such.
